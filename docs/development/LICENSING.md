# Выбор лицензии

Version 1.0.0

Автор: Sergey Fundobny (silverbull@mail.ru) + GPT-6

Дата и время последнего изменения: 261014-184253

Лицензия пока не выбрана. Этот документ сравнивает варианты, не предоставляет
прав от имени владельца. Само наличие публичного репозитория не заменяет LICENSE.
Рекомендация для инфраструктурной Python-библиотеки — Apache-2.0; MIT подходит,
если приоритетом является минимальная сложность условий.

| Вариант | Плюсы | Цена и ограничения |
| --- | --- | --- |
| MIT | Короткая; допускает коммерческое использование и закрытые производные | Сохранение copyright/лицензионного уведомления; нет явного патентного grant; улучшения можно не возвращать |
| Apache-2.0 | Разрешительная; явный патентный grant участников и условия его прекращения | Длиннее; сохранять notices, отмечать изменения, переносить NOTICE при его наличии; нет обязанности открывать улучшения |
| BSD-3-Clause | Разрешительная; отдельно запрещает endorsement именем автора без разрешения | Нет явного патентного grant; для этой библиотеки немного преимуществ перед MIT |
| MPL-2.0 | Изменённые покрытые файлы при распространении остаются доступны в исходниках; можно сочетать с закрытым большим приложением | File-level copyleft требует учитывать происхождение/изменения файлов и предоставление исходников; сопровождение сложнее |

Все четыре допускают коммерческое применение; «бесплатно» не означает
«запрещено продавать». MIT/Apache/BSD не требуют вернуть изменения владельцу.
MPL относится к покрытым файлам при распространении, а не автоматически ко всему
приложению, которое использует библиотеку.

Первоисточники: [MIT](https://opensource.org/license/mit),
[Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0),
[BSD-3-Clause](https://opensource.org/license/bsd-3-clause),
[MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).

До первого публичного релиза нужно выбрать вариант, добавить официальный LICENSE,
согласовать copyright/год, metadata и правила notice. Отдельно проверить лицензии
зависимостей и происхождение logo/assets. Лицензия проекта не перелицензирует
сторонние компоненты; опциональные зависимости тоже имеют собственные условия.
Нельзя считать этот перечень завершённым юридическим аудитом поставки.

Проверка metadata установленного тестового extras-окружения: aiohttp 3.14.5 —
Apache-2.0 AND MIT, pystray 0.19.5 — LGPLv3, Pillow 12.3.0 — MIT-CMU,
pywin32 312 — PSF. Это сведения конкретных distributions, не заключение о каждой
будущей сборке и не проверка их полного набора notices. Для самостоятельного
Windows-комплекта с включёнными зависимостями особенно важно учесть условия pystray;
выбор MIT/Apache для собственного кода не меняет лицензию этой зависимости.
