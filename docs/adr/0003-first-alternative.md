# ADR 0003 — первая альтернатива Telegram

Version 1.0.0

Автор: Sergey Fundobny (silverbull@mail.ru) + GPT-6

Дата и время последнего изменения: 260928-100331

Статус: предварительный выбор для плана, ожидает полевой проверки.

## Контекст

Telegram недоступен с части серверов пользователя, телефон — Android.
Главная первая потребность — уведомления; общий чат с командами также входит
в целевой продукт. Почта резервная, MAX исключён пользователем.

## Решение

Включить ntfy вместе с Telegram в scope 0.1. Matrix оставить следующей интеграцией
для общего чата и команд. Custom outbound adapter доступен уже в первой версии.
Не обещать доступность endpoint по стране без испытания реального пути доставки.

## Обоснование и альтернативы

ntfy позволяет начать с узкого publish-контракта. Matrix охватывает более широкий
чатовый сценарий, требующий дополнительного client state и отдельного решения
об encrypted rooms. Gotify и Pushover остаются кандидатами, если ntfy не пройдёт
полевую проверку. Signal-интеграция требует отдельной оценки сопровождения.

Официальные источники, сравнение и проверочные сценарии:
[CHANNELS.md](../CHANNELS.md). Это инженерный выбор по текущей задаче,
не утверждение о недоступности остальных сервисов.

## Условие пересмотра

Если ntfy не обеспечивает приемлемое получение на целевом Android/сетях или
полноценный чат становится обязательным для первого релиза, пересмотреть порядок
в пользу Matrix либо другого проверенного кандидата. Результат полевого теста
фиксируется отдельно; этот ADR сам по себе тестом не является.
